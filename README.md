# ①課題名
コンビニスイーツ研究所（チーズアカデミーサイト）

## ②課題内容（どんな作品か）
- 仕事帰りのコンビニで「どれにしよう？」と迷う時間を楽しくするための、セブン-イレブン・ローソンの推しスイーツ紹介サイト
- 「このサイトについて」「推しスイーツ」「今月の注目」「公式サイト」「アンケート」の5つのセクションで構成
- HTML / CSS で作成

## ⑤工夫した点・こだわった点
- Google Fonts（Zen Maru Gothic）で、スイーツに合うやわらかい雰囲気にした
- ナビゲーションのページ内リンクで、各セクションへすぐ移動できるようにした
- 写真を並べて、見た目で選びたくなるレイアウトにした

## ⑥難しかった点・次回トライしたいこと（又は機能）

- 次回はスマホ表示にもきれいに対応させたい
