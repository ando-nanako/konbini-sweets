# コンビニスイーツ研究所

## デモ
https://ando-nanako.github.io/konbini-sweets/

## 紹介と使い方
仕事帰りのコンビニで「どれにしよう？」と迷う時間を楽しくするための、セブン-イレブン・ローソンの推しスイーツ紹介サイトです。

- このサイトについて：サイトのコンセプト紹介
- 推しスイーツ：各コンビニのおすすめスイーツ
- 今月の注目：今月チェックしたいスイーツ
- 公式サイト：各コンビニ公式サイトへのリンク
- アンケート：ニックネーム・好きなコンビニなどを回答できるフォーム

## 工夫した点
- Google Fonts（Zen Maru Gothic）で、スイーツに合うやわらかい雰囲気にした
- ナビゲーションのページ内リンクで各セクションへすぐ移動できるようにした
- 写真を並べて、見た目で選びたくなるレイアウトにした

## 苦戦した点
- CSS でのレイアウト調整（画像の並べ方・余白の取り方）
